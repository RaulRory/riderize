# Revisão arquitetural (2026-03-29)

## Evolução desde a revisão anterior
- Introdução de `AppError` e mapeamento de erro por transporte.
- Introdução de portas explícitas para cache e validação.
- Controllers com configuração via DI.
- Resolvers GraphQL extraídos para uma factory com cache centralizado.

## Riscos pendentes
- Controllers ainda capturam exceções e relançam erro genérico, perdendo `AppError`.
- Rotas de `registration/ride` sem `/` inicial.
- Contrato de autenticação e assinatura JWT ainda inconsistente.
